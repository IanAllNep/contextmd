# Acme Shop — Agent Instructions

These instructions apply to every coding agent working in this repository.

## Project overview

Acme Shop is a small e-commerce app with a Python backend and a React frontend.
See [architecture](backend/architecture.md) and the [styling guide](frontend/styling.md).

## Workflow

- Run `make test` before you finish a task.
- Keep pull requests small and focused on a single change.
- Never create database migrations automatically.
- Ask before adding a new third-party dependency.

## Code style

- Use descriptive variable names; avoid abbreviations.
- Write docstrings for every public function.
